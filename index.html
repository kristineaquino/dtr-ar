Add employee

Name is built automatically from Last name, First name and the middle initial. Payroll type follows the status: PLANTILLA / COS are REGULAR, SPES / GIP / EE are MONTHLY. Supervisor and Sector are dropdowns (managed in the Supervisors page and Settings); the supervisor's position fills in automatically. Names are shown as LAST NAME, FIRST NAME M.I. (the initial comes from the middle name). The earliest of Start as COS / EE / plantilla is the first day of service and the End date is the last day: the DTR, AR and WFH Report show nothing (not even dates) outside that range. Employees tagged RESIGNED or TRANSFERRED no longer appear in the Employee dropdown.

Rename this app

Changes the name of the app from “PESO DTR & AR Portal” to any name you want. It does not affect printed DTR or AR forms.

Excel database

Once connected, every change is saved straight into that Excel file (one sheet per table) and the file is loaded each time you open the portal. Works in Chrome and Edge. Keep the file closed in Excel while using the portal, otherwise saving is blocked.
